About

I'm a software engineer. Since 2022 I've been designing services, APIs and distributed systems that need to be fast, correct and boring in production — the kind that calculate payouts, orchestrate async work and keep running when traffic doesn't behave.

At Booking.com I'm on Traveller Intelligence in the Connected Trips unit, building the backend and data services behind personalised traveller experiences. Before that, at Xoxoday, I built the incentive computation engine and a multi-agent LLM assistant, and at ElasticRun I re-architected forecasting services into event-driven microservices on Azure, starting as an intern.

I care about performance, reliability and pragmatic design: systems that scale predictably, not accidentally.
